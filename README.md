# Bone Fracture Detection Using Computer Vision

This project applies computer vision and deep learning techniques to detect and segment bone fractures from X-ray images.

## Project Overview

The project compares multiple deep learning models for fracture detection and segmentation in medical X-ray images.

The implemented models include:

- YOLOv8
- SegFormer-B2
- U-Net++ with EfficientNet-B4

The models were trained and evaluated to compare their performance in detecting fracture regions.

## Project Files

- `Yolov8CV_.ipynb` — YOLOv8 implementation
- `segformerCV.ipynb` — SegFormer implementation
- `unetppCV.ipynb` — U-Net++ implementation
- `ComputerVision_Report.pdf` — Full project report
- `ForPresentation.pdf` — Project presentation

## Objective

The main objective of this project is to investigate and compare different deep learning architectures for automatic bone fracture detection and segmentation from X-ray images.
